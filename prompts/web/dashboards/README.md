Data-dense interfaces used by people who use them every day: dashboards, admin panels, CRM, and ERP.

> **Status: planned for v1.1.** This folder has no entries yet. Its scope and
> intended contents are documented below so the taxonomy is stable and links resolve.
> See [ROADMAP.md](../../../ROADMAP.md) for the release plan.

## Scope

Data-dense interfaces used by people who use them every day: dashboards, admin panels, CRM, and ERP.

> [!IMPORTANT]
> These are applications, not marketing surfaces. The brief listed Dashboard, Admin Panel, CRM, and ERP as website prompts; they are owned here because their design constraints -- density, repeat use, keyboard operation, and speed over persuasion -- are entirely different.
