# Web

Public-facing web surfaces: multi-page sites, conversion pages, internal applications, and the design decisions behind them.

## Folders

| Folder | Owns | Status |
| --- | --- | --- |
| [websites/](websites/) | Multi-page site archetypes | Complete |
| [landing-pages/](landing-pages/) | Single-goal conversion pages | Planned v1.1 |
| [dashboards/](dashboards/) | Internal applications, admin panels, CRM, ERP | Planned v1.1 |
| [ui-ux/](ui-ux/) | Visual and interaction design | Planned v1.1 |

> [!IMPORTANT]
> A landing page is not a small website and a dashboard is not a marketing surface. The three are separated because their design constraints differ entirely.
